Ollama setup ⚙️

RogerChat talks straight to Ollama running on your computer. Each reply gets your latest message plus the saved memory below, not the full chat transcript.

This memory stays in this browser's local storage and is sent to your local Ollama model with each prompt.

If your browser blocks the connection, run Ollama with browser access enabled (OLLAMA_ORIGINS), then refresh this page. GitHub Pages cannot access your machine unless Ollama is running locally.
