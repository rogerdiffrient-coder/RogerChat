Ollama setup ⚙️

RogerChat talks straight to Ollama running on your computer. It doesn't send chat history or keep old messages.

If your browser blocks the connection, run Ollama with browser access enabled (OLLAMA_ORIGINS), then refresh this page. GitHub Pages cannot access your machine unless Ollama is running locally.
